# GFT × Corvid — Network Finance Studio

Interactive strategic model for independent grocery inventory financing and GFT redemption economics.

## Features
- Live, editable demand, pricing, APR, incentives, capture and sell-through assumptions
- GFT $0.75 per qualifying redemption revenue model
- Brand funding, USDC annualized incentives, grocer margins, facility sizing, scenarios and CSV export
- Local scenario storage and shareable input URLs
- Mobile-friendly light blue-gray interface

## Deploy
Static HTML, no build step. Deploy index.html to Vercel as a static site.

## Notes
Hypothetical financial model; no live wallet, POS, custody, or chain connection. Corvid partnership and pricing are not verified. USDC itself does not generate staking yield.
